## 시작

오래 미뤄둔 개발 블로그를 드디어 시작합니다. 여기에는 주로 TypeScript, React 내부 동작, 그리고 평소 궁금했던 것들을 깊이 파고드는 기록을 남길 생각입니다.

## 왜 또 블로그인가

검색으로 글을 읽다 보면 "답은 주지만 이유는 생략된" 글이 많습니다. 그 공백을 제 방식대로 메꿔 보려 합니다.

```ts
function 왜(): string {
  return "원리를 알면 다음 문제를 풀 때 편하다";
}
```

## 앞으로

- **typescript**: 타입 시스템의 쓸만한 패턴과 함정
- **deep-dive**: 이벤트 루프, 클로저, 실행 컨텍스트 같은 기저 동작
- **react**: 렌더링, 리렌더링, 그리고 그 사이의 모든 것

읽어주셔서 감사합니다.
